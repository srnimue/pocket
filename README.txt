Prompt Pocket 試作版

PixAI / SDXLなどで使うお気に入りプロンプトを、カテゴリ・タグ・参考画像つきで保管するためのブラウザアプリです。

主な機能
・カテゴリ切替（初期：キャラ / 衣装 / 髪型 / 表情 / ポーズ / 構図 / 背景 / その他）
・カテゴリ追加・削除
・一覧カードをタップしてプロンプト即コピー
・お気に入り
・タイトル / タグ / 本文を横断検索
・Prompt / Negative Prompt個別コピー
・Prompt＋Negativeまとめてコピー
・参考画像保存
・JSONバックアップ / 復元
・新規登録が上に表示

使い方
index.htmlをブラウザで開いて使用できます。GitHub Pagesにそのまま配置しても動作します。

注意
データはブラウザのlocalStorageに保存します。ブラウザデータを削除すると消える場合があります。定期的に設定画面からJSONを書き出してください。
